# reference_o_declaration

sample_pack と全く同じ形状のモデルを、パーツのグループ宣言に
`o`(object)を使って書き出した参考データです。sample_pack 本体は
`g`(group)宣言を使っています(一部のソフトは`o`の繰り返し宣言を
正しく扱えず、ファイル全体を単一オブジェクトとして読み込んでしまう
ことがあるためです)。

このフォルダには `data/` も `assets/<namespace>/vehicles/` もなく、
単体では乗り物・武器を一切定義していないため、誤って
`tudursvehiclemod-addons/` 配下に置いてもアドオンとして機能する
ことはありません。あくまで両宣言方式の見た目・お使いのソフトでの
読み込まれ方を見比べるための参考データです。
